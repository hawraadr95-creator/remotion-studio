# Remotion Studio

A Remotion project (React + TypeScript) for programmatic video creation.

## Setup

```bash
npm install
```

## Development

Start Remotion Studio to preview and edit compositions:

```bash
npm start
```

## Rendering

Render the default composition to `out/`:

```bash
npm run build
```

## Compositions

- `StudioReady` — a 1080x1920 (vertical), 30fps, 5-second composition displaying
  "Remotion Studio Ready" with a smooth spring-based entrance animation.
